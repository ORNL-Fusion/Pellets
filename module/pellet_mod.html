PELLET

PELLET_MOD is an F90 module of routines that calculates the ablation of solid hydrogenic or impurity pellets in a plasma

References:

W.A.Houlberg, L.R.Baylor 6/2004 W.A.Houlberg, F90 free format 8/2004

Contains PUBLIC routine:

PELLET - solves for pellet ablation along a trajectory in a plasma

Private procedures

hydrogenic ablation rate for Kuteev model
impurity ablation rate for Kuteev model impurity ablation rate for Sergeev model hydrogenic ablation rate for Macaulay model hydrogenic ablation rate for NGS model auxiliary ablation routine for NGS model electron heat flux at pellet surface for NGS model fast ion heat flux at pellet surface for NGS model hydrogenic ablation rate for Parks model hydrogenic ablation rate for Parks model arbitrary Q impurity ablation rate for Parks model impurity ablation rate for Parks 2012 model
impurity ablation rate for Parks 2016 model for Li, Be, B 4th order Runge Kutta routine for time stepping
